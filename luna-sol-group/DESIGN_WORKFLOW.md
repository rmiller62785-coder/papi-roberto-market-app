# Luna Sol Design Operating System

The Luna Sol design standard is an **Operating Evidence Room**: an editorial consulting experience fused with inspectable decision products. Every route must help a visitor identify a decision, inspect the evidence, understand the intervention, and take one focused next action.

## Team workflow

1. **Evidence audit** — inventory claims, artifacts, products, logos, images, and sources. Label each item as public evidence, personal scope, reconstructed artifact, or working product.
2. **Narrative architecture** — define the visitor decision for each route before styling it. Use the sequence thesis → evidence → intervention → action.
3. **North-star frames** — approve the homepage first viewport, one featured-work row, and one product surface. These three frames establish the system.
4. **System build** — lock typography, color, spacing, grid, surfaces, evidence states, controls, form fields, and local navigation.
5. **Route rollout** — implement the shared shell first, then homepage, case dossiers, products, insights, and private operations surfaces.
6. **Editorial and claim review** — independently check attribution, personal scope, source labels, dates, and the boundary between engagement output and public company outcomes.
7. **Red-team QA** — test 390, 768, 1024, and 1440-pixel layouts; keyboard flow; reduced motion; contrast; image crops; empty/error states; asset weight; and focused next actions.

## Five release gates

A route passes only when it has:

- An identifiable executive decision.
- A clear visual and narrative hierarchy.
- Credible, correctly bounded evidence.
- A working and accessible interaction.
- One focused next action.

## Experience modes

- **Public firm experience:** editorial, human, evidence-led.
- **Case dossier:** compact masthead, proof register, chapter rail, intervention, evidence room, next decision.
- **Decision product:** operating problem, live product, methodology, boundary, artifact, consulting handoff.
- **Private Firm OS:** instrument-grade command center organized around engagements, decisions, risks, evidence, and delivery.

## Motion and accessibility

Motion communicates state, sequence, or cause. It never decorates. Prefer progressive CSS view transitions, transform and opacity only, and complete reduced-motion support. Meaningful text is never smaller than 11 pixels. Every hover state has keyboard parity, every control has a visible focus state, and color never carries status alone.
